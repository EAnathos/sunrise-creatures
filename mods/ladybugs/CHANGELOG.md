# Changelog

Each version's section says what changed in it (`cargo creature release` needs one before it tags the version).

## 0.1.1

- Released through Sunrise's new registry: built from this repository by the registry's release workflow, attested by
  GitHub, and reviewed before it is listed.
- Its shared state is locked the library's way (`creature::sync`), never held while it calls the game. Needs Sunrise
  Creatures 0.3.5.
- The code is under PolyForm Noncommercial 1.0.0, the artwork the author's (`LICENSE`, `LICENSE-ART.md` in the
  package).

## 0.1.0

- First release on Sunrise: ladybugs on the flowers of meadows, forests and swamps in five kinds (seven-spot,
  two-spot, twenty-two-spot, orange, harlequin), flying short hops between flowers, crawling and climbing about,
  gathering at night and in the cold, sheltering under leaves in the rain; one that lands on a player standing still
  gives Luck for as many minutes as it has spots; caught in the glass jar, it settles on a flower patch; chickens peck
  them up; the "All the spots" fact.
- Needs Sunrise Creatures 0.3.3.
